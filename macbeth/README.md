### Reading controls

Every scene has previous/next links at the top, an act-contents link, and a footer linking to the whole-play index, cast, report, and XML source. The links cross act boundaries, so the play can be read linearly without returning to an index.

## Source and fidelity

The scene files preserve the source’s speeches, stage directions, and act/scene boundaries. The XML remains authoritative for TEI identifiers, through-line metadata, and encoding detail; this Markdown edition is a navigational reading projection, not a replacement for the source.
